About This Function

f(x,y) = cos(2πx) + cos(2πy) + cos(2παx)

This function has 3 independent frequencies: $(1,0)$, $(0,1)$, and $(\alpha,0)$. When $\alpha$ is irrational, these are incommensurate and $f$ is truly quasiperiodic.

The function range is $[-3, 3]$. Slide c across this range to watch the level set topology change.

This is precisely the function studied in Dr. Roberto De Leo's NSF-funded research "Numerical Analysis of Quasiperiodic Topology" at Howard University.

Novikov's Problem (1982)

S.P. Novikov asked: for a quasiperiodic function on the torus, are the connected components of its level sets open trajectories (curves winding around the torus) or closed loops (bounded circles)?

Physical Meaning

In a metal under a strong magnetic field, electrons move along level sets of the Fermi surface (a quasiperiodic function on the 3-torus). Open trajectories cause the electrical resistance to grow linearly with field strength — a measurable signature observed in experiments on metals like lead.

Key result: When $\alpha$ is rational, all level sets are closed (periodic). When $\alpha$ is irrational, the level set topology can change dramatically — some components become open trajectories that densely fill strips of the torus.

Guided Tour

  1. Start here (α = √2, c = −1.5): one blue closed loop in the interior — a bounded level-set component.
  2. Drag c up toward 0: the loop expands. Near c ≈ −0.73, it hits the boundary and turns orange — the level set has opened into an infinite trajectory.
  3. Drag c further to 0 or +1: multiple orange open trajectories — these extend across all of R² in the Novikov sense.
  4. Try α = φ (golden ratio) — the "most irrational" number, hardest for level sets to close.
  5. Increase resolution to 600–700 for sharper curves (takes ~0.5s longer to compute).
