What the plot shows

f(x,y) = cos(2πx) + cos(2πy) + cos(2παx)

The plot draws all points where the function equals the selected value c. Moving c changes the height being sliced, so the curves can split, merge, close, or run out of view.

The parameter α controls how the x-direction repeats. Rational values create repeating patterns. Irrational values create quasiperiodic patterns that do not line up exactly.

This example is connected to Dr. Roberto De Leo's work on quasiperiodic topology at Howard University.

Why this matters

Novikov's problem asks what happens to these level curves over the whole plane: do they close into loops, or do some keep traveling without closing?

Physical connection

In solid-state physics, related curves describe how electrons move in certain metals under a strong magnetic field. Whether those paths close or stay open can affect measurable electrical behavior.

This page only shows one finite window at a time. An orange curve means it leaves the current view; it does not, by itself, prove what the full curve does far away.

Suggested steps

  1. Start with α = √2 and c = −1.5. Look for blue loops that close inside the view.
  2. Move c toward 0. The curves will change shape as the level value changes.
  3. If an orange curve reaches the edge, drag the plot to follow it.
  4. Try φ for a strongly irrational example and compare it with rational values like 1/2 or 2/3.
